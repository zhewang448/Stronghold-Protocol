# v0.3.3-extended.3 发布记录

日期2026-10-27（Asia/Shanghai）。基础游戏0.3.3；Windows启动器保持1.2.0。本版不改变战斗规则。

## 更新内容

- 同盟大厅统一房间浏览、筛选、搜寻和取消；不限版本、不限难度可独立组合，仍遵守明确指定条件。
- 匹配进入原等待室，房主手动开始；不自动填AI，不切换已有房间规则。
- 控制台房间、上一局、历史记录及回放显示玩法版本，程序版本单独保留；跨局汇总增加版本筛选。
- 历史回放校验并加载原版本数据与bounds；实时观察同步版本、内容身份和便利规则，修复暂停／继续。
- 补齐卸装、插件选择／刷新、联防跳过投票代操作；目录随换局／版本／插件刷新；接通心跳RTT和当前在线状态。
- 保留主线首页往返、聊天气泡、叠层飘字和阶段操作布局修复；更新联防伤害及领袖战尝试说明。
- 修复发布检查发现的match.*插件只读意图拦截、大厅资讯栏缩放守卫及主机更新诊断的i18n边界标记。

## 更新方式

完整assets.zip用于新安装或较旧版本；lite.zip需要自行准备素材。增量update.zip支持v0.3.3-extended.1和v0.3.3-extended.2完整安装，结束对局并备份后更新，不可单独启动。

启动器沿用1.2.0；本次没有新增启动器功能。1.1.0及更早版本先手动下载启动器附件、关闭旧窗口后替换EXE。已用1.2.0的玩家无需重复替换相同版本。各包与启动器统一提供SHA256SUMS.txt及绑定本标签的Ed25519签名。
