# v0.3.3 本地扩展回归修复

## 已复现根因

- 建房后“无效的请求”：room.card 服务端仅检查当前卡池，错误拒绝 seat-art 已声明的非卡池干员；大厅同步与等待室同步各发一套，名片皮肤会被另一套清空或反复拒绝。
- 游戏页合并采用了上游入口，漏掉本地 MatchCommunication、RoundHistoryPanel、PingLayer/PingTools、公告、HUD测量与联防投票接线。
- BriefingScreen保留旧双栏DOM，却套用了上游新版单栏CSS；禁用干员按盟约分组的模型和渲染被替换成平铺。
- 结算回合伤害、结算名片、玩家座位色、调配皮肤随机/清空/导出按钮、道具图鉴及部分移动端/公告/标点/主机工具样式被遗漏。

## 修复范围

- 接受且校验 seat-art 目录内的名片干员与皮肤；仍拒绝不属于该干员的皮肤及未知记录。统一单一同步管线，保留重连重试；旧失效皮肤安全回退。
- 恢复旧双栏盟约页面、禁用干员按盟约分组（组内阶级序）、策略阶段敌人信息和局内分组详情。
- 恢复局内文字聊天/历史/头像气泡、每回合统计和干员伤害排行、标点、公告、联防投票、HUD避让。
- 恢复结算伤害入口、名片头像和回放图像兜底，调配默认卡片视图/显式列表、随机皮肤、皮肤目录与重试、道具图鉴。
- 保留上游历史版本、按干员设置、伤判、图片皮肤、晋升图标与版本缓存修复。未改模拟引擎或生成数据。
