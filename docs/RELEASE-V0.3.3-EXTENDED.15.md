# v0.3.3-extended.15 · 本库首发作战试算、真实训练场与图形战报

日期：2026-11-13（Asia/Shanghai）。基础游戏 0.3.3，Windows 启动器 1.4.1。

## 本库首发：作战试算

从大厅「干员调配」附近进入，所有玩家均可使用，无需创建房间、开启开发者模式或输入管理密钥。先在真实战场试搭配，再用同条件数据比较收益。

- **真实训练场**：单干员木桩与阵容模拟，复用局内棋盘、小人、攻击范围、血条和技能弹道；点击或拖拽部署、装备，点选单位调整技能、模组、普通 / 精锐与朝向。
- **同条件 A/B**：复制方案后修改搭配，快速比较总伤、DPS、治疗、承伤、漏怪和用时；桌面支持同步双屏，手机使用单战场与详情 / 结果面板。
- **图形战报**：伤害类型构成、头像贡献排行、有效治疗 / HPS、承伤、单位明细及累计 / 区间曲线；支持暂停、倍速、重播与进度定位。
- **独立保存**：草稿、最多 20 个命名方案和文件导入 / 导出；读取个人调配副本，训练修改不写回，也不计入正式战绩。
- **五个内置版本**：使用本服启用版本各自的数据与规则，覆盖普通回合及一至两个阵地的领袖战。缺少三维素材时退回二维或头像战场，仍可部署与计算。

单干员默认 60 秒，可选 30 / 60 / 120 秒；伤害按实际扣血统计，召唤物归所属干员，平均 DPS 包含初动与空转。快速计算、实时演练与回放共用确定性模拟和统计路径。测试木桩和手动外部盟约加成为训练假设；整备经济、完整多回合、联防及插件试验继续使用已有工具。

图片、三步入门见[本库特色图鉴](FORK-FEATURES.md#作战试算)，详细范围与统计口径见[作战试算说明](TRAINING.md)。本库首发指这套面向玩家的试算、训练场、比较与战报体验；底层模拟、局内渲染及统计沿用项目已有能力。

## 规程与资源改进

- 规程在策略后从每阶六个正式槽位选择零至二名；原四个版本保留候补与批量选择。同步核心 / 附加盟约禁用和卡池约束。
- 规程领袖战显示伤害前三名干员；接入官方机变表、敌方数值修正和信标限制，保留本库多人分组、独立库存、救援和队友速查。
- 「素材与资源」加入逐干员配音和只读完整性检查，区分所选预载就绪与全资源完整性；保留动态可选下载、导入、缓存和后台预载。
- 附已独立发布的启动器 1.4.1，支持下载代理选择和独立更新。

本版包含上游 dev 从 `b1ca5efb` 至 `f8a6619b` 的适配。来源、冲突取舍与规则假设见[迁移记录](UPSTREAM-DEV-20261112.md)。规程相对上一版有 232 个黄金场景变化，四个历史版本黄金保持不变，逐项见[黄金变化清单](UPSTREAM-DEV-20261112-GOLDEN-MOVES.json)；作战试算自身不改变正式战斗规则。

## 下载与升级

Windows 新安装推荐 **StrongholdProtocolLauncher-v1.4.1-win-x64.zip**。手动安装下载同版 **lite、common-art、local-art、fx-art** 四个 ZIP，合并其中的 Stronghold-Protocol 文件夹；需要动态动画时再合并 **dynamic-art.zip**。新安装默认不下载动态动画。

**增量包直接支持 v0.3.3-extended.14**，不能用于新安装；更早版本可先升级至该版，或使用启动器重新安装。附件包含 SHA-256 校验、Ed25519 签名、素材索引及增量索引，更新器据此校验并选择下载路径。

升级前结束对局、导出个人数据并保留 logs；规程规则更新后，旧未完成对局不保证跨版本恢复。取消动态下载不会删除已安装动画。

## 已知边界与验证

规程仍使用重建棋盘，部分官方整场场景和资源使用回退。重型场景、同步双屏与大量单位对设备负载敏感；实体手机温升和二十名真人整局性能尚未验收。试算结果对应所选版本、配置、时限与随机种子的一次运行，不用于概括所有实战情况。

发布回归、五版本黄金、实际附件、升级与独立副本回滚的命令、原始输出、退出码及哈希保存在发布验证记录中；最终结果随公开 Release 说明列出。
