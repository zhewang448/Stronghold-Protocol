# 动态外观显示修复（2026-11-06）

用户反馈五项问题：名片底图图标、动态禁用置灰、详情头像皮肤、四号位表情位置及银灰动态商店裁切。

## 行为与改动

1. 名片底图入口使用本库 `Icon image` 的内联 SVG，绿色图片标识就是当前设计；不加载外部图标文件，不是图片资源错误。本次保留该入口及文字提示。
2. 动态小图以 Canvas 覆盖静态图片。原禁用/灰暗规则只匹配 `img`，导致动画播放时失去状态提示。将相同滤镜扩展到动态图层，覆盖禁用成员/未上场缩略图、资金不足的商店与晋升卡、补位列表、等待室掉线、结算离开成员。商店原样式和突出人像模式都保留渐变遮罩；不暂停动画、不改变购买资格。
3. 公共干员详情与点击的缩略图统一采用本机已选外观。数据读取仍独立于本人补位/自选及潜能，不把公共条目视为本人持有。明确的队友 owner 使用队友皮肤；公共清除、他人皮肤开关和无主单位边界保留。本人公开状态暂缺时使用本机外观；有明确公开状态时继续以公开状态为准。
4. 表情/文字气泡按实际 `offsetParent` 计算坐标，监听头像/行/名单尺寸变化；可见头像旁的气泡仅受 HUD 可见边界和实际横向重叠的商店限制，不再受名单底边挤压，首尾四个座位使用同一规则。多人长名单继续沿滚动定位，气泡图层保持在列表裁切之外。
5. 银灰「不融冰」旧裁切坐标与本机官方动态骨架不同，导致小图取到衣摆。使用官方半身像/头像与实际暂停首帧作特征匹配，半身 116 匹配/108 内点，头像 64 匹配/53 内点；骨架 SHA-256 与素材身份保持不变。证据写入 `docs/research/dynamic-crops.json`，只更新该皮肤；由工具同步研究注册表和资源清单，不手改 `data/assets.json`。

## 重建

```powershell
node tools/update-dynamic-catalogue.mjs --frames-only --frames=docs/research/dynamic-crops.json
node tools/install-dynamic-illustrations.mjs 'char_172_svrash@ambienceSynesthesia#4' --offline
```

`--frames-only` 只同步已注册身份的有效头像/半身矩形和证据，不更新官方皮肤表来源、技能或名单。官方图片、骨架和截图存本机忽略目录，不加入 Git。
