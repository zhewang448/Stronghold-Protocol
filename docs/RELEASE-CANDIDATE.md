# v0.3.1-extended.10 · 多域名存档找回与控制台体验

基于上游 v0.3.1，上一正式扩展版为 v0.3.1-extended.9。

## 本版更新

- 控制台配置正式网址、多个旧网址和四种展示或跳转模式；找回面板自动汇总旧站摘要，无需逐站确认，旧站一键迁移直接到新站预览。
- 恢复前自动备份本机数据、背景和音乐，支持撤销；原站数据保留，历史时间缺失显示未记录。
- 首页找回、导出 / 导入入口集中在开始按钮下方，手机、大字号和中英文布局优化。
- 控制台导航立即响应，保留未保存草稿、筛选和既有记录；保存与失败反馈更清楚，尊重减少动态效果偏好。
- 保留 Windows x64 启动器、桌面安装入口、二十人同盟及全部既有玩法。

## 使用与升级

新旧网址均须可达并提供更新后的前端。项目配置不会创建 FRP 绑定、DNS 或证书；旧 HTTP 存档须从原 HTTP 入口读取。首次自动打开可能被浏览器阻止，点击一次查找全部旧站即可重试。

完整包用于新安装；轻量包需保留或另行安装素材；签名增量适用于未修改的 v0.3.1-extended.9 完整安装。Windows EXE 为独立附件，先升级同版游戏目录再解压到根目录。

升级前结束活动对局并备份 logs 和浏览器个人数据；升级后刷新游戏与控制台。主机 local/ 配置和玩家存档不进入附件。
