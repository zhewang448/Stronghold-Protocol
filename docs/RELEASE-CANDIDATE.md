# v0.3.3-extended.12 大更新发布说明

本次集中更新动态立绘、自选候选与战场界面，并带来客户端偏好管控、控制台可选登录、默认方舟鼠标与部署吸附开关。基础游戏仍为 0.3.3，启动器升级为 1.4.0。详见 [完整发布说明](RELEASE-V0.3.3-EXTENDED.12.md) 和 [特色图鉴](FORK-FEATURES.md)。

新增浏览器、控制台与启动器的动态素材可选下载：新装默认不下动画，保留静态图；更新保留已有文件，可之后补装。基础安装改由精简程序包＋common/local/fx 三组签名素材分包组装，dynamic-art 独立可选（单体完整 ZIP 超过 GitHub 2 GiB 限制），另提供从已发布 v0.3.3-extended.9 / v0.3.3-extended.10 升级的增量包。升级前结束对局并导出个人数据；跨版本恢复快照不保证兼容。若喜欢这次大更新，欢迎给本库点一个 Star ⭐。
