# v0.3.1-extended.11 · 统一资源下载与在线状态修复

基于上游 v0.3.1，上一正式扩展版为 v0.3.1-extended.10。

## 本版更新

- 首页收敛为「素材与资源」，面板只保留一个主下载按钮，移除重复的完整素材下载入口。
- 安全缓存可用时分级预载；普通 HTTP 或缺少缓存能力时自动使用兼容下载全部素材，关闭下载窗口即暂停。
- 保留素材 ZIP、完整安装包和文件夹导入，导入不会启动下载；缓存 ZIP 导入 / 导出单独说明并按能力启用。
- 修复资源操作切换时对话框被卸载；保留下载重试、暂停与缓存复用。
- 控制台在线状态取自当前房间席位，修复断线 / 重连状态滞后，兼容独立 match host。

## 使用与升级

完整包用于新安装，轻量包需保留或另行安装素材；签名增量适用于未修改的 v0.3.1-extended.10 完整安装。Windows EXE 单独提供，先升级游戏再解压到同版根目录。
升级前结束对局并备份 logs 和浏览器个人数据；升级后刷新游戏与控制台。主机 local/、密钥、日志和玩家存档不进入附件。

## 验证与边界

资源下载 / 导入、缓存 ZIP、HTTP 兼容和控制台在线状态的专项、浏览器、全量、golden 与制品验证结果见 GitHub Release。未通过或未运行项如实列出，不把专项通过表述为完整 CI 全绿。
