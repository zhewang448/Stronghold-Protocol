# v0.3.1-extended.9 · Windows 服主启动器与桌面安装

基于上游 v0.3.1，上一正式扩展版为 v0.3.1-extended.8。正式附件、SHA-256 清单及 Ed25519 签名见 GitHub Releases。

## 本版新增

2026-10-22 新增 Windows x64 服主 EXE 启动器，提供与游戏一致的视觉和开服 / 服务管理入口。
关闭窗口保留后台服务，停止服务需点击窗口内的停止按钮；EXE 仍需 Node.js 22+ 与同版目录。
构建及兼容要求见 [启动器说明](../launcher/README.md)，验收边界见 [验收记录](HOST-LAUNCHER-VALIDATION.md)。
Windows x64 启动器通过本版独立 `launcher-win-x64.zip` 附件提供；先安装或升级同版游戏，再解压 EXE 到根目录。

首页与大厅保留添加到桌面入口；有浏览器邀请时直接显示原生安装框，否则显示手动安装与可信 HTTPS 要求。
Edge 路径为「⋯ → 更多工具 → 应用 → 将此站点作为应用安装」。控制台「维护与扩展 → 桌面安装入口」
提供默认开启的显示开关，实时同步首页、大厅与横屏提示，跨重启保留。

## 保留的 .8 功能

- 解除四人房间限制，默认四人、开局前可选 4 / 8 / 10 / 16 / 20 人，空位可由 AI 补齐。实际开局人数决定固定分组，二十人分 A–E 五组，组内共享干员 / 装备库存，策略与机变按组并行。
- 联防每场仍最多两名助手，按组继续后续轮次、最多五轮，支持投票跳过后续联防；首领战仍按两人分场，不扩大棋盘。
- 保留普通四人及以下的首领退出、隐藏关层数快照与单组策略跳过行为。扩容规则按开局实际人数生效，二十人容量但仅四人开局仍按普通四人处理。
- 回档、重启恢复、只读插件、战绩与监控墙适配扩容；字母 / 数字房间码恢复兼容旧文件名，后续多轮联防保留完整统计和漏怪来源。
- 漏怪 / 未出场记录超出客户端上限，或非首领必要结果超出消息大小时，改用同一战斗输入在服务器重算，避免截断后少扣血。原始漏怪按来源结算，联防现场分裂 / 召唤子怪仍免扣，每回合扣血上限不变。
- 二十席统一玩家色，统计支持分组 / 全部筛选、点击突出和回合详情固定滚动；刷新保留选中状态，手机沿用横屏布局。
- 同盟创建先选择难度，新建同盟默认开启 AI 最后选择；修复监控墙换页缩放，控制台「维护与扩展」提供 Issues 反馈入口。
- README 加入多人扩容说明和截图，索引逐项感谢上游、扩容、UI 与聊天作者；具体来源见 NOTICE.md。

## 下载与升级

完整包适合新安装，轻量包需保留或另行安装素材。增量包适用于 v0.3.1-extended.8 完整安装；不适配或验证失败时，控制台自动回退同版完整包。EXE 另附同版 Windows x64 ZIP，不包含游戏、Node.js 或素材。

升级前结束活动对局，备份 logs 和浏览器个人数据。升级后刷新游戏和控制台；恢复文件绑定版本及规则指纹，不保证跨版本续接未结束的对局。更新恢复按安装顺序使用逆向事务，不逆迁移用户数据；详细步骤见 [部署说明](DEPLOY.md)。

普通启动入口即可使用扩容，房主在等待室底部齿轮「同盟设置 → 人数上限」中调整；开局后不能改变。完整规则和来源见 [扩展联机说明](EXPANDED-COOP.md)。
