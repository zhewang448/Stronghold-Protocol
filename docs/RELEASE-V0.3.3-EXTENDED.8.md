# v0.3.3-extended.8 发布准备

日期：2026-11-03（Asia/Shanghai）。基础游戏 0.3.3，Windows 启动器 1.3.0。

## 本轮改动

- Issue #16：控制台「结束整局」与回合操作分开，确认明确判负及整局结算。
- Issue #17：随机盟约统一处理手动、高亮超时和强制分配，揭示真实策略并只发一次 1 生命/1 金币补偿。
- Issue #18、PR #14：干员/装备库存只进入私有视图；同池交易主动刷新。顶部盟约成员显示实时余量，区分共享、独立和个人自选库存。
- Issue #19、PR #15：提取客户端 CharacterSkinHooker 替换表、模式与挂点；补齐发射者优先级、弹道/浮游单元/链式特效传播与缺资源回退。
- Issue #20：八套时装分别安装头像、半身像、立绘及模型，新时装可在等待室名片中选择、同步和刷新保留。
- Issue #21：1:1 头像裁剪支持拖动、缩放及键盘；同房间分享、更新、移除和重连同步；盟约提示支持悬停/触屏/键盘，AI 保留策略头像。
- 控制台统一搜索和 18 项新房默认配置，每项独立设置房主权限；客户端恢复默认保留难度，版本变化仍需全员同意，校验失败不留下部分修改。
- 观战席数字输入保留草稿并确认提交，修复旧复选框样式造成的不可读/难输入问题。

## 来源与适配决策

PR #14/#15 按本库补位、自选、分组卡池和特效提取流程适配，不直接覆盖已有模块。
新增 PR #22 固定提交 4d598f26354330c7450b78d42366a9296f303fd8 存在未定义的 notifyPersonal，成功存储后上传/删除仍抛错；房间 AvatarFrame 未传 playerId，局内 PlayerAvatar 未接入。保留已验证的本库裁剪与同房间分享实现，避免两套缓存和权威源并存。

随机盟约、头像分享、房间默认配置与便利开关为用户指定的 [ASSUMED] 扩展。官方模拟路径、已发布版本和 golden 期望不变。游戏美术不进入 Git，发布素材按本机有效清单单独打包。

## 兼容与发布边界

默认值只影响新房；权限变更立即生效并保留旧房选择。恢复默认不会踢出当前成员；容量、版本、插件或权限不满足时保留原配置。
头像只向同房间成员分享，编号和战绩仍在本机。独立卡池、个人自选和跨组库存不会互相套用。
升级前结束对局并备份个人数据，跨版本恢复快照不保证兼容。准备新的签名附件与 GitHub 草稿，正式发布为后续动作；不覆盖旧 release 文件。
