- 观战席数字输入保留草稿并确认提交，修复旧复选框样式造成的不可读/难输入问题。

## 兼容与发布边界

默认值只影响新房；权限变更立即生效并保留旧房选择。恢复默认不会踢出当前成员；容量、版本、插件或权限不满足时保留原配置。
头像只向同房间成员分享，编号和战绩仍在本机。独立卡池、个人自选和跨组库存不会互相套用。
升级前结束对局并备份个人数据，跨版本恢复快照不保证兼容。准备新的签名附件与 GitHub 草稿，正式发布为后续动作；不覆盖旧 release 文件。
