# v0.3.3-extended.14 · 规程·序列Ⅰ、队友速查与可露希尔终端主题

日期：2026-11-10（Asia/Shanghai）。基础游戏 0.3.3，Windows 启动器沿用 1.4.0。

本次发布将已适配的规程赛季、队友速查、资源补全和可露希尔终端主题提供给玩家。原四个盟约版本继续可选，保留本库 4–20 席分组、独立卡池、批量自选、动态外观、取景同步、主机配置、个人数据与恢复工具。

## 规程·序列Ⅰ

- 新增第五个玩法版本「规程·序列Ⅰ」，大厅默认选择；单人可选极速模拟和规程等级 1–20，同盟沿用四档难度。
- 接入本赛季 37 名干员专属技能、26 个盟约、61 个策略及对应指令、驻守、装备和敌人。
- 单人开局从两组核心盟约中选择一组；同盟随机置灰半数核心盟约。规程自选每阶六名候选加两名候补，可明确携带零至六名。
- 规程使用五格装备栏，强制获得的溢出装备进入暂存；旧四版沿用自己的规则。无版本的旧记录和回放仍指第二期下半。
- 官方版本房间支持观战者接替 AI，继续受服主权限、房间开关和真人投票约束；玩法插件须声明兼容版本。

## 队友与界面

- 队友速查显示盟约、在场干员、精英标记和策略，适配二十席与分组名单；只显示公开在场信息。
- 修复魔王 S3 背景遮挡，保留特效前景及其他特效的排序。
- 新增本机可选「“全能的”可露希尔」终端主题，覆盖商店、HUD、回合提示、大厅角色与九个动作预览；支持中文、日语语音，对局主题语音默认关闭。
- 主题采用已核对的原生卡框、等级图与按钮底图，回合窗口按原生边框缩放；互动按实际动作长度播放，失落动作衔接对应待机。默认仍使用原界面，切换主题不改变玩法。

## 下载与升级

新安装推荐 **StrongholdProtocolLauncher-v1.4.0-win-x64.zip**。手动安装下载同版 **lite、common-art、local-art、fx-art** 四个 ZIP，合并其中的 Stronghold-Protocol 文件夹；需要动态动画时再合并 **dynamic-art.zip**。可露希尔主题的本机素材随对应素材分包提供，源码安装另见 [主题说明](TERMINAL-THEMES.md)。

**增量包直接支持 v0.3.3-extended.13**，不能用于新安装；更早版本可先升级至该版，或使用启动器重新安装。附件提供 SHA-256 与 Ed25519 签名，更新器按签名索引选择下载。动态动画继续可选，取消不删除已有动画。

升级前结束对局、导出个人数据并保留 logs。规程加入后对局规则指纹变化，旧对局快照不保证跨版本续局。每个附件均须低于 GitHub 的 2 GiB 限制。

## 已知边界与来源

规程尚使用重建的 19×21 棋盘，未映射十张官方整场场景；淤困之茧的独立图鉴图标沿用回退。部分 AI 预演和重型场景对设备负载敏感，二十名真人整局性能与实体手机温升尚未验收。主题尚未逐帧重放原生 Unity 粒子系统与完整语音概率触发器。
