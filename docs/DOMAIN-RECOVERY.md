# 域名搬迁与本机存档找回

控制台「设置 → 维护与扩展 → 域名与存档迁移」填写正式网址及最多 12 个旧网址。
完整网址包含协议、域名和端口，不包含路径、查询参数和片段。旧站可设名称、启用状态和列表顺序。
保存到被忽略的 `local/personal-data.json`，刷新页面生效；不修改隧道、DNS 或证书。
管理读写仅在本机鉴权控制台 `/api/domain-recovery`；游戏端口仅提供只读、no-store 的配置。

## 旧站的四种模式

- 正常游戏：保留游戏并显示新网址与迁移链接。
- 搬迁提示：显示旧站本机存档摘要和新网址，由玩家选择迁移或直接前往。
- 智能跳转：有存档先显示搬迁页，没有存档前往新站；无法读取存储时留在提示页。
- 直接跳转：普通访问前往新站，迁移专用页面仍可访问。

由浏览器的 `location.origin` 精确匹配协议、域名、端口，不依赖代理是否重写 Host。
新旧隧道必须继续可达，并提供更新后的前端。HTTP 存档必须从原 HTTP 入口读取。
本功能不需要 CORS，不使用第三方 iframe 扫描，也不会自动创建 FRP 绑定。

## 玩家找回

首页入口位于「开始」按钮正下方：「找回数据」与「导出 / 导入个人数据」并排显示，
不再放在右上角。找回使用薄荷色强调，导出/导入为同组次要操作；两者保持至少 44px 点击高度。
小横屏下放宽登录区，简化装饰与素材提示，保留完整按钮文字和弹窗返回焦点。大厅原入口继续保留。

从旧站主动点击「迁移存档并前往新站」时，在同一次点击中打开正式站新窗口，
直接传送该旧站的完整个人数据，新站立即显示存档预览，不再要求打开旧站检查或再次选择。
点击前明确提示传送内容包括背景和音乐，原旧站保留。新站仍需点击「确认并恢复」，
恢复前备份和撤销机制不变。传送期间保持旧站打开，收到新站确认后显示送达。
弹窗拦截、存储失败、来源窗口关闭或三分钟超时均可重试，也可回退至手动找回。
传输仅使用定向 postMessage，双方绑定窗口、精确 origin 和随机 nonce；新站只接收配置的启用旧站。
网址片段只含源站及一次性 nonce，绑定后清除，不携带存档内容、不经过服务器。

正式站首次访问显示找回弹窗；关闭后不重复提示。首页和大厅的「找回数据」可再次打开。
打开找回面板时自动读取所有启用旧站的回复；只复用一个顶层辅助窗口依次访问各旧站，
返回昵称、头像、编号、战绩数、配置数、最近进入时间及最近战绩时间，不再逐站检查或确认。
首次自动打开若被浏览器阻止，只需点击一次「查找全部旧站」；点击首页/大厅找回按钮时提前保留辅助窗口。
玩家直接从汇总结果选择一个存档，复用同一窗口读取完整快照、预览，最终确认后才写入。
每站超时 10 秒后继续下一站；无法连接、存储拒绝、无存档分别显示，失败项可单独重试。
自动回复仅在旧站配置的正式 origin 发起，且当前旧 origin 在启用列表时允许；仍校验来源窗口、精确 origin、nonce。
素材、存档内容不进入 URL 或服务器；摘要读取不会改写最近进入时间。
原始数据不会发送至服务器或写进 URL；跨窗口校验精确 origin、来源窗口与 128 位随机 nonce。
弹窗拦截、窗口关闭和超时给出可重试状态，不把连接失败解释成没有存档。

最近进入时间存为 `sp.pref.lastEnteredAt`，只在真实进入游戏时更新；检查旧站不会更新。
历史存档无此字段显示「未记录」，不会用当前检查时间或导出时间补造。

## 备份与撤销

两种导入入口均先将当前个人数据及背景、音乐备份到当前 origin 的 IndexedDB
`sp-recovery-backup`。备份写入失败则停止恢复。成功恢复后刷新页面生效；原旧站数据保留。
最近一次导入前的备份可在「找回数据」撤销，恢复个人命名空间、战绩及媒体的原值，
移除导入新增的个人配置，保留临时会话、插件授权等非个人命名空间。
处于同盟中时不允许恢复或撤销。清理浏览器存储会同时删除此本机备份。

每次恢复只选择一个来源；战绩按原记录 ID 合并，同名配置按所选存档覆盖。
恢复码、旧单域名配置 `migrationSource` 和原 `#sp-migrate` 授权入口继续兼容。

`node --test test/domain-recovery.test.js test/personal-data-config.test.js test/ui/personal-data.test.js`
覆盖配置校验、鉴权、保存失败、时间不变与精确撤销。
设置 `SP_E2E=1` 和 `CHROME_PATH` 后运行
`node --test test/ui/domain-recovery.e2e.test.js test/ui/personal-data.e2e.test.js`，
覆盖两个旧 origin、授权、选择、恢复、撤销、智能/直接跳转例外、首次提示及控制台保存。
