# 作战试算

在大厅「干员调配」附近打开「作战试算」，或访问本服 `/training/`。首次跟随大厅版本，各方案保存自己的版本与内容标识；更新数据后检查配置并重新试算。无需创建房间或输入工作台密钥。

## 单干员测试

搜索并选择干员，从个人调配复制技能、模组、潜能与练度。可切换普通/精锐、装备、朝向与站位；需要手动部署的召唤物在干员配置中选择。设置木桩生命、防御、法抗、数量，点击「开始试算」。木桩不移动、不攻击，时长默认60秒，可选30/60/120秒。远离木桩、朝向错误或需要受击/治疗条件的技能可能没有输出；可移动干员或改用阵容模拟。

「盟约加成（测试假设）」手动指定外部加成；高级条件可选择策略，仅运行战斗部分。测试场地与木桩是人工训练条件 [ASSUMED]，不作为官方关卡。

## 阵容模拟

选择地图、战场区域、回合、难度或规程等级。选择干员后点合法格子部署，点单位编辑，选中后点空格移动；桌面也支持拖动。普通回合使用一个阵地，最终攻势/隐秘核心可用一至两个阵地，阵地数对A/B共用并决定领袖血池。更换地图、战场区域或测试模式会清空部署。

难度选项显示「独立模拟 · 难度」或「同盟模拟 · 难度」。同名难度属于不同模式，保留各自的波次、缩放和领袖规则；规程等级同样标明模式。

盟约人数与阶数由正式对局计数器根据阵容计算，层数是手动填写的初始值。整备经济、整备区计数、整备奖励、插件与联防不在本工具中；这类试验使用原测试控制台或测试房间。

## 方案比较与保存

配置A后使用「复制 A → B」，更改B的装备、技能、层数或站位，然后运行「对比 A/B」。两边共用版本、敌人、难度、地图、时限与随机种子；条件变化会使两边结果过期，单侧配置变化只使该侧过期。结果显示绝对差值与相对百分比；基准为零时不计算百分比。清场更快可能导致总伤更低，应结合漏怪和用时判断。

方案自动记住草稿，命名后可保存最多20个方案，也可导入/导出JSON文件（上限512KiB）。训练存储使用 `sp.training.v1`，个人调配只读，不会写回；浏览器禁用存储时可导出文件。跨域使用需手动导入方案。

## 结果与战斗演示

有效总伤害采用实际扣血，排除溢出；召唤物归所属干员，元素损伤积累不算生命伤害。平均DPS按从部署开始的本场实际秒数计算，包含初动和空转；木桩被击破或波次提前清除时使用提前结束的时长。

「查看战斗」按相同配置与随机条件重算，通过局内渲染器显示单位模型、生命与技能弹道，提供播放/暂停、0.5×至8×、重播与进度拖动；缺素材时降级为二维或头像战场。取消试算、修改条件、切换方案或版本会终止旧任务，不允许旧结果覆盖新配置。计算或数据加载失败时保留配置并提供重试。

## 接口与验证

- `GET /api/training/options?version=<id>`：本服启用版本、内容标识、模式、部署图与默认文档。
- `POST /api/training/build`：`{ document, side: "A" | "B" }`，校验版本、内容、配置和部署，返回正式BattleSpec与训练夹具。只构建，不运行服务器战斗、不写文件。
- 文档 `v: 1` 包含名称、版本、内容标识、模式、公共环境、木桩与A/B玩家配置；使用既有场景的大小、数量和字段校验。

验证：`node --test test/training.test.js test/studio/console.test.js test/ui/combat-metrics.test.js`；浏览器用 `SP_E2E=1 CHROME_PATH=<chrome> node --test test/ui/training.e2e.test.js`；四种语言使用 `node tools/i18n.mjs check --all --strict`。完整回归按仓库约定运行 `npm run ci` 和 `npm run golden`。

## 可操作训练场（2026-11-12）

训练页以局内真实战场为中心，复用原棋盘、干员/敌人小人、攻击范围、朝向轮盘、血条、技能弹道与特效。备战调用 setPrep，展示单位待机动画但不推进战斗；选择单干员后自动寻找能命中木桩的合法落位与朝向。治疗与条件触发技能会提示所需目标，仍可在阵容中测试。

底部单位库分干员、装备、召唤物；点击卡片后点场地可部署，也可拖动卡片到场地。选择干员后点击两个装备槽之一，从装备库选择即可替换；装备可拖至干员所在地格。场上单位可以拖动，落位和转向使用局内朝向轮盘，箭头键/Enter 和触控都可确认。技能通过图标切换，精锐一键切换，模组与更多练度选项在单位面板内。盟约条可展开层数与外部加成。地图、难度、木桩参数、随机条件、策略与方案保存集中在顶部条件抽屉中。

「开始演练」实时推进浏览器Worker，左侧战场与右侧统计共用真实状态；「快速对比 A/B」保留原快速计算。演练状态下只读检查单位，修改需要返回备战，从零帧重新开始；未完成的演练不覆盖上次完整结果。播放、暂停、倍速、重播和进度定位通过同一个Worker会话执行；定位重新创建模拟和渲染状态，清理先前特效，保留同种子结果。

A/B 默认单战场切换，桌面至少1200px可开启同步双屏；两边共用逻辑时钟与固定视角，不因第二个视图重复推进模拟。一方提前结束后保持其末帧，另一方继续。手机保持单屏，竖屏在战场下切换单位库/详情/统计，横屏保留单位侧栏。

画面默认3D、精简特效并读取原画质设置；展示选择独立保存于 sp.training.view.v1，不改个人调配。缺少三维素材自动使用已有二维棋盘；引擎初始化失败使用现有头像战场，仍可配置和演练。未提取游戏素材不阻止计算。

## 图形战报与统计口径

结果在侧栏优先显示：有效总伤害、全程平均DPS、有效治疗/HPS、总承伤、实际/设定用时、击杀/目标、漏怪，以及木桩或领袖剩余生命。大数随界面语言使用万/K等单位，悬停可查看精确值，详细表格显示精确数字。

伤害构成复用局内物理/法术/真实/元素配色，显示数值和百分比；元素损伤积累不计入生命伤害。干员贡献使用原头像和分段条，可切换伤害、治疗、承伤、击杀排序，显示占比、DPS或HPS；点击干员可定位到场上单位。召唤物的输出、治疗、承伤与计数归属所属干员。

「详细战报与曲线」展开输出曲线、单位明细和A/B比较。曲线按游戏秒记录累计伤害、治疗和承伤，可查看区间DPS/HPS；区间速率除以真实采样间隔，包含空转，提前结束的不足一秒区间也使用实际时长。快算、实时演练与定位重算复用同一个统计器，旧采样在重播或跳转时重建，避免重复累计。A/B曲线只使用当前有效结果或当前演练状态，提前结束的一方不会伪造后续数据。

单位明细包含总伤害、DPS、有效治疗、HPS、承伤、击杀和攻击动作次数。承伤含自身生命流失，不能直接当作敌方输出；攻击次数是引擎动作计数，不是每次伤害跳数。A/B表格明确显示B−A的差值和相对百分比，基准为零时不生成无穷百分比。
