- Windows 启动器升级至 1.2.0，新增独立自更新：自动检查、用户确认、Ed25519验签、关闭后替换并重新打开；后台游戏服务器保持运行。

1. 旧启动器首次升级：单独下载1.2.0附件，关闭旧窗口后替换EXE。此前1.1.0不能自动发现并安装自身更新。
2. 游戏实例：已安装v0.3.3-extended.1可通过控制台升级或手动增量包；更旧版本使用完整包。首次升级由旧更新器执行，启动器仍建议单独换新版。
3. 后续：启动器顶部自更新独立管理EXE；新版控制台同步根目录及已登记独立位置。下载验签不等于安装，待关闭状态不冒充成功。
