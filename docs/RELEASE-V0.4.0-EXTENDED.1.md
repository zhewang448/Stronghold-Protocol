# v0.4.0-extended.1 · 官方主题与开局界面、房间装备区

日期：2026-11-15（Asia/Shanghai）。基础游戏 0.4.0，附 Windows 启动器 1.4.1。

## 玩法与房间

- 新增房间规则「独立装备区」：四个盟约版本可在开局前启用 5 格永久装备区，装备不占 10 格干员手牌；未使用装备可跨休整保留，不阻止准备就绪。默认关闭，控制台可设置新房默认值与房主修改权限。
- 规程·序列Ⅰ自带装备区，房间选项固定勾选且不可修改；切回其他版本后恢复保存的偏好与权限。
- 修复规程新盟约的预选校验与名片自动底图，补齐乌萨斯、伊比利亚、莱塔尼亚；保留手动选择、清空、成员及观战同步。
- 同步上游核心盟约禁用、装备获得与融合、驻守、领袖和地形修复，保留本库分组卡池、独立库存、救援及作战试算。

## 界面与体验

- 官方主题统一框架，完善商店卡盒、空栏、阴影、冻结／刷新按钮与顶栏查看按钮，支持主题独立导入及预览；保留动态立绘、取景、语音默认关闭及服主偏好控制。
- 首页、大厅、房间、战前简报和策略页更新呈现与进场反馈，二十席房间保留 A–E 分组；策略页仍使用已有自选与准备流程。
- 首页和大厅增加主动「观看开场」入口，支持两套赛季、跳过、重播、焦点与音乐恢复；启动时不会自动播放。
- 队友速查改为盟约／在场干员／策略三列，支持悬停展开、头像点击、横向拖动与切换战场收起。
- 房间官方立绘加载失败时按所选外观、默认立绘、占位回退，并有限重试；网络恢复、重聚焦或切换来源后可恢复。
- 修复本机未启用登录时，控制台入口误跳登录页的问题。

## 下载与升级

Windows 新安装可用 **StrongholdProtocolLauncher-v1.4.1-win-x64.zip**。手动安装合并本版 **lite、common-art、local-art、fx-art** 四个 ZIP 的 `Stronghold-Protocol` 文件夹；需要动态立绘时再合并 **dynamic-art.zip**。新安装默认不下载动态动画，已有动画不会因取消下载而删除。

**增量包直接支持 v0.3.3-extended.15**。更早版本先升级至该版，或通过启动器重新安装。本版跨基础版本升级到 0.4.0，请先结束对局并保留日志及个人数据备份；旧未完成对局不保证继续恢复。附件附 SHA-256、Ed25519 签名、素材索引与增量索引。
