# v0.4.0-extended.3 · 第 84 轮、设置搜索与战场 v6

2026-11-26（北京时间）。基础游戏 0.4.0，附 Windows 启动器 1.4.1。

## 对局

- 修复规程最终攻势和隐秘核心的战中普通叠层。效果当场生效，战后写回（#28）。乌萨斯临时层数独立结算，联防沿用房规。
- 规程从第 8 回合起每回合收入为 11，极速模拟首回合收入为 6。合成晋级奖励在可领取的休整期结束时失效。同步盟约、干员、驻守、敌人和召唤物规则修正。

## 界面与战场

- 设置分六类，支持跨分类搜索。名片干员可跨期选择，创建同盟时沿用房主上次修改的「AI 队友最后选择」，服主锁定优先。
- 规程盟约显示首档人数门槛及实际阶段。三套主题的分段圆盘和二十席队友速查继续使用本库布局。
- 战场场景升级到 v6。MAP10 盐坨子炮增加原版模型与特效，干员攻击时模型会朝向目标，整备区设备图标更清楚。规程增加 Terra Archive 社区英文译文，外观插件可添加时装语音。
- 修复 Windows 在退出或重启后因 PID 被复用而误判守护器仍在运行的问题。

## 安装与升级

- **已有 v0.4.0-extended.2** 可在结束对局后从本机控制台安装增量。恢复快照与规则指纹绑定，跨版本的未完对局可能需要重开。
- **新安装**可用启动器自动下载。手动安装时合并 lite、common-art、local-art、fx-art 内的同名游戏目录。dynamic-art 为可选动态素材。
- **源码安装**运行 `node tools/setup.mjs --scenes` 刷新场景。 [本地素材与 MAP10 说明](ASSETS.md#map10-salt-cannon)
