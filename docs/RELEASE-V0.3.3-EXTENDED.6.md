# v0.3.3-extended.6 发布记录

日期：2026-10-29（Asia/Shanghai）。基础游戏为 0.3.3，Windows 启动器沿用 1.2.0。

## 修复

- 领袖回合观战时，地面标点使用实际战场坐标，不再错误套用自身半场的棋盘变换；自身休整画面也可在共享战场的可见地块标点。
- 控制台刷新保留滚动位置、展开状态、未提交输入和焦点；聊天管理、更新设置、资源监控与实时统计曲线保留对应的交互状态。
- 作战统计和每回合干员伤害排行按棋子 uid 分开累计；同一棋子在多轮联防和不同回合的记录继续汇总，召唤物仍计入其所属干员。

## 兼容与限制

- 旧对局记录若已将同名干员合并，缺少棋子 uid，无法恢复各实例的数据；没有 uid 的旧记录继续显示已有汇总。
- 标点发送的 500 毫秒冷却保持不变。简化棋盘只覆盖它实际显示的棋盘区域。
- 升级前结束进行中的对局并备份个人数据；跨版本恢复快照不保证兼容。增量包仅用于其清单列出的旧版完整安装，不可单独启动。
- 既有敌人血量倍率限制不变：控制台跨局汇总仍会合并默认和自定义倍率对局，回放页不单独显示倍率。
