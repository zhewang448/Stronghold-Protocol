# v0.3.3-extended.13 · 战斗修复、新模组、AI 与房间取景同步

日期：2026-11-08（Asia/Shanghai）。基础游戏 0.3.3，Windows 启动器沿用 1.4.0。

本次更新选择性适配原上游 dev 的规则修复与内置 AI，补齐官方 CN 2.7.91 模组数据，并让玩家在房间调整的立绘位置和大小同步显示。四个玩法版本、4–20 席分组、独立卡池、主机工具、个人数据和可选动态素材继续保留。

## 战斗与官方数据

- 同一名干员的两件同款装备分别生效，避免后一件覆盖前一件的属性和持续效果。
- 愧悔魂灵圣杯的分伤方向修正：附近地面敌人仅承受 5%，其余由圣杯承担真实伤害。
- 乌尔比安 S3 的移动和返回清除元素损伤及爆发状态；落点在脚下或没有其他合法落点时，也执行原地移动。
- 死亡之眼、节日爵士乐手仅在持续施法时停步，正确处理控制打断与技能冷却。
- 鸭爵只替换下路敌人，同一玩家同一回合替换成同一种，不同玩家可以不同；缇缇 S2 生命比例相同时优先最后部署者。
- 补充敌方“国度”的地块范围提示。
- 第二期下半增加号角 ISW-A「号角特限证章」、凛御银灰 CSR-X「邀约」、缪尔赛思 TAC-D「“缪尔赛思和朋友们”」、溯光星源 DEC-X「远方问候」。号角集成战略专用条款在本模式不生效；凛御银灰默认仍不带模组。
- 克莱门莎 S3 的同格再次选取间隔按官方新表由 5 秒改为 3.5 秒；历史版本继续使用各自固定表。

## 内置 AI

每回合确定主盟约，改善核心成员采购、职业队叠层、队友避让、寻呼补员和阿戈尔吞噬；最终攻势更注重对首领的输出阵容、路线、分散站位和余钱装备。保留本库卡池分组、独立库存、AI 预设与托管入口。

预演后的阵容不再被后续经济流程覆盖。离席者的策略轮选由团队规则代选，避免占用歌利亚并保持 0 LP。额外候选会增加部分计算量，继续使用分步执行和房主浏览器预演回退。

## 房间立绘位置和大小同步

在房间直接拖动或通过「更换立绘 → 立绘调整」修改后，同房间成员与观战者会收到拥有者的缩放、水平和垂直位置。静态、动态和上传图片使用同一取景；不同外观分别保存，刷新与重连后恢复。

接收方不再套用自己本机对同一干员的设置。取景只影响外观，不影响战斗数据；失败重试和旧服务器兼容沿用现有同步机制。

## 下载与升级

推荐使用 **StrongholdProtocolLauncher-v1.4.0-win-x64.zip**。手动新安装下载同一版本的 **lite、common-art、local-art、fx-art** 四个 ZIP，合并其中的 Stronghold-Protocol 文件夹；需要动态动画时再合并 **dynamic-art.zip**。

动态动画仍为可选下载，静态头像、半身图和立绘在基础包中。取消下载不删除已有动画。

**增量包直接支持 v0.3.3-extended.12**，不能用于全新安装；更早版本可先升级至该版，或使用启动器重新安装。更新器按签名索引校验程序和素材。升级前结束对局、备份个人数据并保留 logs；本次战斗规则变化后，旧对局快照不保证跨版本续局。

每个公开附件均须低于 GitHub 的 2 GiB 限制，发布提供 SHA256SUMS.txt 与 Ed25519 签名。启动器自身代码与 1.4.0 相同。
