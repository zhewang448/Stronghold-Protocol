# v0.3.3-extended.5 发布记录

日期：2026-10-27（Asia/Shanghai）。基础游戏 0.3.3，Windows 启动器保持 1.2.0。

## 功能和限制

- 房主可在房间设置选择 0.1–100 倍敌人血量，默认 1 倍；普通敌人与原有难度、回合倍率乘算，领袖共享血池也乘算。
- 非 1 倍的对局在局内难度旁显示倍率；房间不参与公开匹配，玩家本机统计默认将该对局标为非官方并排除。
- 控制台跨局汇总目前仍将自定义倍率对局与默认对局合并；回放页面不单独显示房间倍率。普通战斗的录制输入保留出场倍率，但自定义倍率整局录制及播放未做端到端验证，领袖共享血池回放仍有既有同步限制。
- 升级前结束活动对局并备份个人数据。完整、精简和增量包的适用范围以发布附件及其清单为准。
