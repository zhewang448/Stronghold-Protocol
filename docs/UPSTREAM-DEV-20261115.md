## 兼容与推定

角色动画、主题布局等上游已标注的 [ASSUMED] 保持原边界；本库额外的多人、库存、房规和训练能力仍是扩展。共享驻守计数、复制特质等推定来源见上游相关历史条目。主题 ZIP 保存在浏览器独立图库，个人备份保留主题选择但不打包该图库；跨设备需要保留并重新导入主题包，缺少包时使用默认呈现。
