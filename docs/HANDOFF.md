# 项目维护交接

更新时间：2026-10-29（Asia/Shanghai）。

## 1. 当前代码

维护主线 origin/main，固定上游 v0.3.3。旧候选文档作历史。

## 2. 当前版本

当前版本为 `v0.3.3-extended.7`，基础游戏 0.3.3，Windows 启动器 1.3.0。

- 整合上游 v0.3.3 与四个玩法版本，默认开放四版、默认第二期下半；保留 4–20 席分组、聊天、标点、每回合统计、结算、回放和七名联动。
- 时装扩至 146 名干员／224 套，补齐一期皮肤和模型；保留随机范围、锁定与每局自动随机，调配支持分项导入导出。
- 随时查看历次上游／扩展更新内容；自动提醒独立开关和已读，手机参照公告栏适配安全区、横屏、大字及触屏滚动。
- Windows 启动器 v1.3.0 支持独立下载安装、自更新、签名素材分包、便携 Node、多实例、监听端口＋索引发现、手动导入和回收站删除。
- 修复房间便利选项、主机观战接替 AI 权限及默认重启恢复，保存的 false 保留；设置分组和触摸热区修复。控制台在线人数按真人连接及访问域名准确投影。
- 完整包、精简包、增量包及启动器配套发布，提供签名校验。升级前备份；跨版本恢复快照不保证兼容。外部 LLM 不包含于游戏发行包。

本版增加可选独立卡池和队友救援、AI 策略预设、持有状态预设和主机监控，并优化跨版本增量更新、素材分包与启动器下载。

## 3. 维护

发布不强制重启现有服务。结束对局并备份后正常升级；PREP 快照绑定规则指纹，不承诺跨版本续局。实例命名不移动原安装目录，私钥和本机凭据不进包。
