## 发布修正与边界

更新健康检查按候选启用版本对应的本地数据目录计算build指纹，避免默认四版后误报不一致；子进程不继承调用者的inline代码参数，避免验证脚本递归执行。主机控制仍要求原凭据。旧浏览器兼容去掉:has，使用显式rs-foot--options菜单类。默认房间快照只加入已批准的convenience与AI权限字段，基础内容哈希向量不变。签名工具纳入规范命名的独立启动器ZIP。

素材隐私扫描的41个数字账号名命中经审计均为官方特效浮点数。本次用既有SP_PACKAGE_SCAN_USER=0仅跳过账号子串检查，home路径及保留路径扫描始终执行。未提交游戏素材、配置、日志、凭据或私钥。
