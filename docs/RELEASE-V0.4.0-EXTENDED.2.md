# v0.4.0-extended.2 · 第 83 轮、规程战场与盟约图标

2026-11-19（Asia/Shanghai）。基础游戏 0.4.0，附 Windows 启动器 1.4.1。

## 对局与界面

- 同步上游第 83 轮的干员、装备、召唤物、敌方机制和规程指令修正。大厅可预选玩法插件，建房沿用已选内容和服主策略。
- 规程·序列Ⅰ使用新版官方战场场景。休整期、赛前「本局信息」的缩略图和放大预览使用对应材质。场景不可用时显示格子图。
- 顶栏恢复卫戍协议终端贴图、乌萨斯齐心团和可露希尔的原生盟约分段环、配色及文字叠放。阶段在上沿，层数叠在下沿，名称紧接下方。金色数字表示普通与临时层数合计，详情可切换上一项和下一项。修复规程商店图标、作战试算徽标和盟约条的显示。
- 「设置 → 界面与操作」可开启上游 #948 的骷髅手动画，并选择自动或 32–128 px 固定大小。新用户默认使用系统指针。
- 「设置 → 战斗显示 → 作战中查看队友」可在本人战斗尚未结束时查看其他阵地。最终攻势和隐秘核心可跨组查看。默认关闭。
- 修复连续设置大厅背景时旧任务覆盖新选择，以及服主设置迁移和锁定状态显示。

## 下载与升级

- **已有 v0.4.0-extended.1** 可在结束对局后从本机控制台安装本版增量。恢复快照与规则指纹绑定，跨版本的未完对局可能需要重开。
- **新安装**可直接使用 Windows 启动器。手动安装时解压 lite、common-art、local-art、fx-art，将各包的 `Stronghold-Protocol` 文件夹合并。按需加入 dynamic-art。
- **源码安装**使用 `node tools/setup.mjs --scenes` 更新 v5 场景。Windows 提取器优先在与游戏相同的磁盘准备临时文件，并在跨盘复制前报告空间需求。已安装完整素材分包的玩家可直接使用场景。 [部署指南](DEPLOY.md) · [素材提取说明](ASSETS.md)
